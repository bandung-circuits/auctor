# Auctor

AI-powered news commentary production pipeline. From a single news lead to a comprehensive analytical commentary article, grounded in historical materialism and centered on Global South perspectives.

## Quick Start

**Group 00** — Quick Research & Summary:
```
Please read agents/00.orchestrator.md and execute strictly according to that Blueprint.

Parameters:
- NEWS_LEAD: [your news lead here — one sentence or a URL]
- EDITOR_NOTES: [optional — your preliminary observations or angles of interest]
```

**Group 10** — Expert-Driven Deep Analysis & Writing (after expert interviews):
```
Please read agents/10.orchestrator.md and execute strictly according to that Blueprint.

Parameters:
- NEWS_LEAD: [same news lead]
- RUN_ID: [the RUN_ID generated by Group 00]
- EXPERT_INPUTS: [expert interview transcripts]
```

## Pipeline

The pipeline is split into two agent groups with a natural break for expert interviews (typically several hours).

```
Group 00 (Quick Research & Summary)
News Lead ─► Background Research ─► Initial Summary
  input        fully automated       fully automated

                    ⏸️ Human conducts expert interviews (hours)

Group 10 (Expert-Driven Deep Analysis & Writing)
Expert Input ─► Process Interviews ─► Generate Questions ─► Deep Research ─► Commentary Points ─► Outline ─► Article ─► Export
 human input     fully automated      fully automated      fully automated    AI + editor        AI + editor  near-auto   script
```

### Group 00: Quick Research & Summary

| Stage | Agent | What Happens |
|-------|-------|-------------|
| 0 | 00.orchestrator | Initializes workspace, coordinates Group 00 |
| 1 | 01.researcher (x10) | 10 parallel researchers collect materials across factual, contextual, reactional, and analytical angles |
| 2 | 02.summarizer | Synthesizes research into event overview, identifies contradictions, proposes commentary directions |

### Group 10: Expert-Driven Deep Analysis & Writing

| Stage | Agent | What Happens |
|-------|-------|-------------|
| 3 | 11.expert-processor | Structures raw expert interview transcripts (human provides input) |
| 4 | 12.question-generator | Reverse-engineers research questions from existing research + expert insights, identifies gaps |
| 5 | 13.deep-researcher (xN) | Focused web research on generated questions (parallel, one per question group) |
| 6 | 14.commentary-designer | Proposes 4-6 argumentative commentary points (human approves/modifies) |
| 7 | 15.outliner | Drafts article outline with section structure and material allocation (human approves/modifies) |
| 8 | 16.writer | Writes the complete ~3,000-word commentary article |
| 9 | scripts/export.sh | Exports article to DOCX and PDF via pandoc, into workspace/{RUN_ID}/_output/ |

## Patterns Applied

Built with the [POMASA](https://github.com/eXtremeProgramming-cn/pomasa) pattern language:

| Pattern | Category | How Applied |
|---------|----------|-------------|
| COR-01 Prompt-Defined Agent | Required | All agents defined as natural language blueprints |
| COR-02 Intelligent Runtime | Required | Claude Code as execution runtime |
| STR-01 Reference Data Configuration | Required | Domain knowledge and methodology separated from blueprints |
| STR-02 Filesystem Data Bus | Recommended | Agents communicate via workspace/ directory |
| STR-04 Business-Driven Agent Design | Recommended | One business stage = one agent; two groups reflecting natural workflow break |
| STR-06 Methodological Guidance | Required | research-overview, data-sources, output-template |
| STR-07 Reverse-Engineered Research Questions | Recommended | Agent 12 generates questions by reverse-engineering existing research + expert input |
| STR-09 Deliverable Export Pipeline | Recommended | scripts/export.sh converts final article to DOCX/PDF |
| BHV-01 Orchestrated Agent Pipeline | Recommended | Two orchestrators managing their respective groups |
| BHV-02 Faithful Agent Instantiation | Required | Subagents read full blueprints; orchestrator only passes parameters |
| BHV-03 Parallel Instance Execution | Optional | 10 research angles in 2 batches of 5; deep research in parallel groups |
| BHV-05 Grounded Web Research | Recommended | Fetch original content; search results are leads only |
| BHV-06 Configurable Tool Binding | Recommended | Prioritize MCP tools (serper, crawl4ai, oxylabs) over defaults |
| QUA-03 Verifiable Data Lineage | Required | Material IDs (M-A-001..., Q1-001...) traced through all stages |

## Human-in-the-Loop

The pipeline pauses for human input at four points:

1. **Between Group 00 and Group 10**: Editor conducts expert interviews (hours)
2. **After Stage 6** (Commentary Points): Editor approves/modifies the argumentative backbone
3. **After Stage 7** (Outline): Editor approves/modifies the article structure
4. **After Stage 8** (Article): Editor reviews final draft, triggers export when ready

The final article (Stage 8) is positioned as "an excellent first draft" for human refinement.
